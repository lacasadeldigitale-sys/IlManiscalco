# 🐎 Il Maniscalco

Applicazione professionale per maniscalchi e professionisti equestri.

## Funzionalità

- 📋 Archivio cavalli con ID univoco
- 🔧 Registro trattamenti e interventi  
- 📅 Calendario eventi con promemoria
- 🏢 Database aziende del settore
- 🔍 Motore di ricerca avanzato

## Tecnologie

- Gradio per l'interfaccia
- SQLite per il database
- Python per la logica

## Installazione

Lo Space si avvia automaticamente su Hugging Face.
